# Single-node distributed

Reserved for real multi-process topologies using no more than eight local HCU
devices.

Subdirectories:

- `collectives/`: all-reduce, all-gather, and all-to-all.
- `tp_ep/`: TP/DP/EP/PP and local DeepEP combinations.
- `split_pd/`: local producer/decode process separation.
- `mooncake/`: local Mooncake producer/consumer integration.
